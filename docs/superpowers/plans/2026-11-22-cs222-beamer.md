# CS222 Beamer deck — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `slides/main.tex` — a Beamer XeLaTeX deck reproducing `slides/source/slide-cs222.pptx.pdf`, with figures cropped from the two papers and tables typeset in LaTeX.

**Architecture:** One master file `slides/main.tex` holds theme/preamble and `\input`s one file per section from `slides/parts/`. A Python tool `slides/tools/crop_figures.py` (PyMuPDF, runs in `.venv-slides`) regenerates every figure in `slides/figure/` from `slides/source/*.pdf`. A `Makefile` in `slides/` runs crop → compile → zip.

**Tech Stack:** XeLaTeX (BasicTeX 2026, TeX Live 2026), Beamer + Metro theme, fontspec, babel(vietnamese), booktabs, tabularx, tikz, PyMuPDF.

**Spec:** `docs/superpowers/specs/2026-11-22-cs222-beamer-design.md`

## Global Constraints

- Compiler: `xelatex`, invoked twice. Must build from `slides/` as CWD.
- All paths relative, ASCII only, no spaces: `slides/parts/01_dta.tex`, `slides/figure/t2l/...`.
- Fonts: only fonts that exist on Overleaf's TeX Live. Body font = Latin Modern (default). No macOS system fonts.
- No `twemojis` in body text (emoji font unavailable on Overleaf). `fontawesome5` only if it loads.
- Vietnamese text preserved verbatim from the source deck unless a line is marked as a new takeaway.
- Every number in a typeset table must be copied from the paper PDF, not from memory or the old slide.
- Figure crops render at 300 dpi, clipping exactly the figure region above its caption.
- Footer columns: `Nhóm 5 -- UIT` | `CS222 -- Prompting \& PEFT` | `\insertframenumber/\inserttotalframenumber`.
- Each task ends by compiling `slides/main.tex` successfully (or proving the new input fails in a way the next task fixes — never leaving the tree uncompilable at a task boundary).

## Review Focus

- **Vietnamese diacritics** under XeLaTeX + `babel[vietnamese]`: mangled glyphs or missing precomposed chars. Expect: every char renders, `ộ ệ ữ ặ ỹ` visible in the rendered PNG.
- **Crop boxes drifting** when a source PDF has a different layout than expected. Expect: each crop contains its full figure and no caption text.
- **Frame overflow**: a slide whose figure + bullets exceed the text area. Expect: `Overfull \vbox` absent from the log, or the figure shrunk.
- **Missing glyphs in tables**: `−`, `≈`, `≤`, `Δ` rendering as blank. Expect: `\ensuremath` or plain text.
- **Theme/font package availability on BasicTeX**: Metro, mhchem-free packages. Expect: `tlmgr install` list recorded in `slides/README.md`.

- [ ] **Step 3: Write `slides/tools/crop_figures.py`**

The tool holds a `CROPS` dict: `{output_relpath: (source_pdf, page_1based, rect_or_None, dpi)}` where `rect` is `(x0, y0, x1, y1)` in PDF points and `None` means "whole page minus nothing". Renders with `page.get_pixmap(clip=..., dpi=300)` for PNG, or uses `pymupdf`'s `show_pdf_page` into a one-page PDF for vector output. Uses `pymupdf` (not `fitz`).

- [ ] **Step 4: Run the tool and verify count**

Run: `.venv-slides/bin/python slides/tools/crop_figures.py && ls slides/figure/t2l slides/figure/gepa | wc -l`
Expected: one entry per row of the design's crop table (≥ 7 figures).

- [ ] **Step 5: Verify a crop is a real image, not blank**

Run: `.venv-slides/bin/python -c "import pymupdf,glob; [print(f, pymupdf.open(f)[0].get_pixmap(dpi=10).samples.count(0)) for f in glob.glob('slides/figure/*/*.pdf')]"`
Expected: every file has a non-trivial number of dark pixels.

- [ ] **Step 6: Commit**

```bash
git add slides/tools/crop_figures.py slides/figure slides/README.md
git commit -m "slides: vector figure crops from the T2L and GEPA papers"
```
