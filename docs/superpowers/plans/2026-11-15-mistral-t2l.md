# T2L on Mistral-7B-Instruct-v0.2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a trustworthy Text-to-LoRA result (5 benchmarks × 4 arms) on Mistral-7B-Instruct-v0.2 on GPU 7, with every heavy artifact stored under `/data/quan.lt/temp/t2l-mistral/`.

**Architecture:** Reuse the existing, tested harness (`src/t2lgepa/`) unchanged in its data/scoring/prompt layers. Add only what differs for this model: configurable binary paths, a Mistral config, a gate module, and a smoke driver. T2L adapters are generated zero-shot from task descriptions by the released hypernetwork; no training on our data.

**Tech Stack:** Python 3.11, uv, vLLM (serving, LoRA hot-swap), PyTorch + transformers + peft (adapter generation), HF datasets, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-11-15-mistral-t2l-design.md`

## Global Constraints

- GPU **7 only** (`CUDA_VISIBLE_DEVICES=7`); no other GPU may be used.
- All weights, venvs, HF caches, adapters and results live under `/data/quan.lt/temp/t2l-mistral/`. Nothing heavy on `/mnt` (28GB free, 95% full).
- Model: `mistralai/Mistral-7B-Instruct-v0.2`. T2L checkpoint: `SakanaAI/text-to-lora` → `trained_t2l/mistral_7b_t2l`.
- Tasks: `gsm8k`, `arc_challenge`, `boolq`, `hellaswag`, `winogrande`. Arms: `base`, `icl3`, `t2l`, `t2l_icl`. Seed `0`. 1,000 items per task.
- Decoding greedy (`temperature: 0.0`) for every reported number.
- Generated adapters must end with `"use_rslora": false` in `adapter_config.json` (r=8, alpha=16, `q_proj`/`v_proj`).
- Gate numbers: published `t2l_icl − base` mean = **+12.6pp**; tolerance ±10pp. Method runs are only comparable within one fingerprint.

## Review Focus

1. **Adapter collapse** — an adapter generated with `use_rslora: true` scores near chance while still "working". G1 must catch it before the grid.
2. **Results-dir mixing** — Gemma results already live in `results/`; Mistral results must never be written there, or tables will silently average two models together.
3. **Wrong GPU** — vLLM or the generator defaulting to GPU 0/6 would disturb other tenants. Every launch step sets `CUDA_VISIBLE_DEVICES=7` explicitly.
4. **Fingerprint invalidation mid-grid** — any commit while the grid runs changes `run_fingerprint` and makes finished jobs non-resumable. Commit code first, then start the grid.
5. **Disk on `/mnt`** — HF default cache is under `$HOME` on `/mnt`; a forgotten `HF_HOME` fills the shared volume and truncates result files (this happened in the previous run).

### Task 3: Gate module

**Files:**
- Create: `src/t2lgepa/mistral_gate.py`
- Test: `tests/test_mistral_gate.py`

**Interfaces:**
- Produces:
  - `CHANCE: dict[str, float]` — `{"gsm8k": 0.0, "arc_challenge": 0.25, "boolq": 0.5, "hellaswag": 0.25, "winogrande": 0.5}`
  - `smoke_failures(base: dict[str, float], adapter: dict[str, float], floor_pp: float = 15.0) -> list[str]`
  - `full_failures(deltas: dict[str, float], published_mean: float = 0.126, tol_pp: float = 10.0) -> list[str]`
  - both return human-readable failure strings; empty list means pass.

- [ ] **Step 1: Write the failing tests**

```python
def test_collapsed_adapter_is_caught():
    base = {"gsm8k": 0.62, "boolq": 0.70}
    adapter = {"gsm8k": 0.04, "boolq": 0.51}
    assert len(smoke_failures(base, adapter)) == 2

def test_working_adapter_passes_even_when_below_base():
    base = {"gsm8k": 0.62, "boolq": 0.70}
    adapter = {"gsm8k": 0.55, "boolq": 0.72}
    assert smoke_failures(base, adapter) == []

def test_direction_needs_four_of_five():
    assert full_failures({"a": 0.01, "b": 0.02, "c": 0.03, "d": 0.04, "e": -0.05}) == []
    assert len(full_failures({"a": 0.01, "b": 0.02, "c": -0.03, "d": -0.04, "e": -0.05})) == 1

def test_magnitude_outside_band_fails():
    assert full_failures({f"t{i}": 0.126 for i in range(5)}) == []
    assert len(full_failures({f"t{i}": 0.30 for i in range(5)})) == 1
```

- [ ] **Step 2: Run to verify failure** — module missing.

- [ ] **Step 3: Implement**

`smoke_failures` fails a task when `adapter[t] < base[t] - floor_pp/100` or `adapter[t] <= CHANCE[t]`. `full_failures` reports when fewer than 4 of 5 deltas are positive, or when `abs(mean(deltas) - published_mean) * 100 > tol_pp`.
